## 0. Используемые технологии
- **HTML5** - многостраничная структура сайта.
- **SCSS (Sass)** - модульная стилизация и адаптивные миксины.
- **Vanilla JavaScript (ES Modules)** - интерактивность без фреймворков.
- **Node.js + npm** - управление зависимостями и запуск SCSS watcher.

## 1. О проекте
`futuretech` - pet-проект многостраничного адаптивного сайта на тему AI-медиа/AI-ресурсов.

Проект демонстрирует:
- аккуратную блочную SCSS-архитектуру;
- переиспользуемые UI-компоненты на чистом JS;
- работу с адаптивом, интерактивными блоками и базовой accessibility-разметкой.

## 2. Ключевые цели проекта
- Практика production-подхода к вёрстке (структура, нейминг, модульность).
- Реализация UI-компонентов без сторонних фреймворков.
- Поддержка адаптива для desktop/tablet/mobile через SCSS-медиа-миксины.
- Отработка интерактивных паттернов: tabs, кастомный select, video player, expandable content, burger menu.

## 3. Страницы и пользовательские сценарии
В проекте реализованы отдельные страницы:
- `index.html` - главная страница с hero-блоком, метриками, карточками и табами.
- `news.html` - новостная страница с вкладками и карточками видео.
- `podcasts.html` - страница подкастов с видеоплеерами и карточками контента.
- `resources.html` - страница ресурсов с табами и отчётами.
- `blog.html` - страница статьи с разворачиваемым текстом.
- `contacts.html` - страница контактов с формой, кастомным select и маской телефона.

## 4. Архитектура проекта
Проект организован по модульному принципу:

- `styles/` - SCSS-архитектура:
  - `helpers/` - функции, миксины и брейкпоинты;
  - `blocks/` - стили отдельных UI-блоков;
  - `_globals.scss`, `_variables.scss`, `_fonts.scss` - базовые слои;
  - `main.scss` - единая точка сборки всех стилей.
- `scripts/` - JS-компоненты:
  - `main.js` - инициализация всех интерактивных модулей;
  - `BaseComponent.js` - базовый класс с proxy-state и автообновлением UI;
  - `Header.js`, `Tabs.js`, `Select.js`, `VideoPlayer.js`, `ExpandableContent.js`, `inputMask.js`.
- `images/`, `icons/`, `fonts/`, `videos/` - статика проекта.

## 5. Реализованный функционал

### 5.1 Адаптивная вёрстка и UI-система
- Реализована адаптивная сетка и типографика.
- Используются CSS custom properties для цветов, шрифтов, теней и размеров контейнера.
- Настроены брейкпоинты для `laptop`, `tablet`, `mobile`, `mobile-s`.
- Применяется компонентный подход к стилям через `styles/blocks`.

### 5.2 Интерактивные JavaScript-компоненты
- **Header / burger menu**:
  - открытие/закрытие мобильного меню;
  - блокировка скролла страницы через класс `is-lock`.
- **Tabs**:
  - переключение вкладок кликом и с клавиатуры;
  - поддержка `ArrowLeft/ArrowRight/Home/End`, `aria-selected`, `tabindex`.
- **Custom Select**:
  - кастомный dropdown с синхронизацией с нативным `select`;
  - управление мышью и клавиатурой;
  - адаптация поведения под mobile/desktop через `matchMedia`.
- **Video Player**:
  - кастомная кнопка запуска видео;
  - показ/скрытие панели управления в зависимости от состояния плеера.
- **Expandable Content**:
  - разворачивание длинного контента с анимацией высоты.
- **Input Mask**:
  - маска телефона на `contacts.html` через `IMask`.

### 5.3 Доступность и UX-практики
- Используются `aria-label`, `aria-selected`, `aria-expanded`, `aria-activedescendant`.
- Реализованы стили для `:focus-visible`.
- Предусмотрены увеличенные интерактивные hit-area для ссылок и кнопок.
- В табах и select добавлена клавиатурная навигация.

## 7. Локальный запуск

### 1) Установите зависимости
```bash
npm install
```

### 2) Запустите отслеживание SCSS
```bash
npm run sass-watch
```

Команда использует `sass --watch .` и автоматически пересобирает CSS при изменениях SCSS-файлов.

### 3) Откройте HTML-страницы
Проект статический, поэтому можно открыть нужные файлы напрямую в браузере:
- `index.html`
- `news.html`
- `podcasts.html`
- `resources.html`
- `blog.html`
- `contacts.html`

Для корректного DX рекомендуется запускать через локальный статический сервер (например, VS Code Live Server).
